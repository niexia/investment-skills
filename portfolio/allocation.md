# 配置政策

> **这是硬约束，不是建议。** `portfolio-review` 用它判断偏离，`AGENTS.md` 要求 Agent 不得自行发明风险预算。
> 以下数值为初始默认值，**需要你确认或修改**；改完删掉本段提示，并在 `docs/changelog.md` 记一笔。

## 1. 目标结构

| 层级 | 目标区间 | 作用 | 工具 |
| --- | --- | --- | --- |
| 核心（宽基指数 + 高确定性价值股） | 60%–80% | 长期复利，低换手 | 宽基 ETF、价值型个股 |
| 卫星（成长股 / 行业 ETF） | 20%–40% | 提高上限，可承受更高波动 | 科技成长股、行业 ETF |
| 现金 | ≥ 5% | 缓冲 + 机会 | 货币基金、活期 |

## 2. 集中度上限

| 项目 | 上限 | 说明 |
| --- | --- | --- |
| 单一核心持仓 | 15% | 按穿透后市值计 |
| 单一卫星持仓 | 8% | 高波动标的更严格 |
| 单一 ETF | 25% | 注意底层重叠 |
| 单一行业 | 30% | 穿透后计算，含 ETF 成分 |
| 单一市场（美股 / 港股） | 70% | 另一个市场至少保留 15% |
| 单一币种 | 70% | 避免汇率单边暴露 |
| 前 5 大持仓合计 | ≤ 60% | 超过视为高度集中 |

## 3. 再平衡

- **触发方式**：阈值触发 + 季度检查，不做日历强制调仓。
- **个股**：权重偏离目标 > 5 个百分点，或突破上限 2 个百分点 → 进入"再平衡评估"。
- **ETF / 大类**：偏离目标 > 8 个百分点 → 进入评估。
- **评估 ≠ 执行**：由人决定是否调整；Agent 只输出偏离与可选动作。
- **不因短期涨跌调仓**：触发条件只看权重与论点状态，不看 1 个月收益。
- 再平衡优先用新增资金与分红，减少交易成本与税负。

## 4. 禁止事项

- 不使用杠杆（融资、保证金、期货）。
- 不做空。
- 不买看不懂的结构化产品、雪球、场外期权。
- 单一标的浮亏超过 30% 时，**不允许**仅因"摊低成本"加仓；加仓必须重写论点。
- 不因为宏观预测调整长期仓位（宏观只影响安全边际要求）。

## 5. 决策权限

- 所有买卖决定由本人做出。
- Agent 可输出：偏离分析、论点状态、估值区间、可选动作类型。
- Agent 不可输出：具体买卖指令、目标仓位数字、择时建议。

## 6. 复盘节奏

| 频率 | 内容 | 产出 |
| --- | --- | --- |
| 每季 | 组合复盘、政策偏离、论点状态 | `reports/portfolio-review/` |
| 每次财报 | 对照证伪条件，更新论点 | `reports/theses/` 新版本 |
| 每年 | 全年决策复盘：流程 vs 结果、错误归因 | 年度复盘 |
