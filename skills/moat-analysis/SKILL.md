# 护城河分析

回答两个问题：**这是不是一门好生意？它的优势能持续多久？**
不估值，不预测股价。

## 何时使用

- `company-research` 的第 3–4 节。
- 用户问"它的护城河是什么""为什么别人复制不了"。
- 不适用：判断短期股价、比较两家公司谁更便宜（用 `intrinsic-valuation`）。

## 输入

必需：公司业务描述、收入结构、主要竞争对手、5 年以上毛利率与 ROIC。
可选：用户调研、渠道反馈（只能作为线索，不能作为结论依据）。

## 流程

### 1. 生意画布

用一页说清：

- 产品/服务是什么，解决谁的什么问题
- 收入模式（一次性 / 订阅 / 抽成 / 广告 / 授权）与收费对象
- 成本结构：固定成本 vs 变动成本，边际成本随规模怎么变
- 价值链位置：上游是谁、下游是谁、公司拿走了多少价值

### 2. 单位经济

尽量量化：

```
单位贡献 = 单位收入 - 单位变动成本
回收周期 = 获客成本 / 单位贡献（订阅/平台型必算）
```

数据拿不到就写"无法量化"，并说明缺什么。不要用行业平均值代替。

### 3. 护城河识别

只认这六种，每种必须给**可观测证据**：

| 类型 | 证据 | 反证 |
| --- | --- | --- |
| 网络效应 | 用户/商家数增长与单用户价值同向 | 用户增长但活跃/留存下降 |
| 转换成本 | 迁移需重新部署、数据不可导出、合同期长 | 客户流失率上升、降价留客 |
| 规模经济 | 单位成本随份额上升而下降 | 规模扩大但利润率下降 |
| 品牌/信任 | 提价后销量稳定、复购率高 | 靠促销维持销量 |
| 牌照/准入 | 牌照数量受限、审批周期长 | 政策放开、新牌照发放 |
| 成本优势 | 资源禀赋、区位、工艺带来的结构性低成本 | 成本优势来自补贴或低价人力 |

**不允许**把"技术领先""管理优秀""先发优势"单独列为护城河——它们必须转化为上面六种之一，否则只是阶段性优势。

### 4. 宽度与趋势

- 宽度评分 1–5：1 = 无，3 = 窄且可被侵蚀，5 = 宽且证据充分。
- 趋势：变宽 / 稳定 / 收窄。用 3 年数据判断：份额、毛利率、客户留存、提价能力。
- 趋势比宽度更重要。宽但在收窄的护城河，估值时应给折价。

### 5. 压力测试（必做）

1. **替代品测试**：如果出现一个价格低 30% 的替代品，客户会走吗？走多少？
2. **新进入者测试**：给对手 100 亿美元和 5 年，它能复制吗？卡点在哪？
3. **去中介测试**：上游或下游能否绕开公司直接交易？
4. **技术路线测试**：所在技术路线被替代的概率与时间窗口。
5. **监管测试**：护城河是否依赖某一项可被修改的政策。

### 6. 定价权

找 3 个历史提价案例：提价幅度、销量变化、毛利率变化。
提价后销量不降 = 有定价权；靠降价保份额 = 没有。

### 7. 企业文化（段永平框架）

读 `knowledge/investors/duan-yongping.md`：

- 是否有"为了长期价值放弃短期利润"的具体案例
- 是否消费者导向（而非只盯对手）
- 说过"不做什么"，是否守住
- 管理层犯错后的处理方式

### 8. 结论

输出四行：

```
生意质量：优秀 / 良好 / 一般 / 差
护城河类型：<六型中的一或两种>
宽度与趋势：X/5，变宽 / 稳定 / 收窄
一句话：这门生意赚的是谁的钱，为什么能持续
```

## 输出

写入报告第 3、4 节。独立使用时输出一份 800–1,500 字的分析，仍按上述四行结论收尾。

## 质量门

- [ ] 护城河能归入六型之一，且有证据
- [ ] 给了趋势判断，不是只给宽度
- [ ] 做过替代品与新进入者测试
- [ ] 定价权有至少 1 个提价案例
- [ ] 没有把"技术领先"直接当护城河
- [ ] 结论是四行格式，没有模糊表述

## 交接

- 上游：`financial-analysis` 的毛利率、ROIC、客户集中度。
- 下游：`intrinsic-valuation` 用护城河趋势决定永续增长率与折现率；`investment-thesis` 用护城河结论作为核心支柱之一。

## 禁止

- 用"品牌知名度高"代替定价权证据。
- 用市场规模大代替公司有护城河。
- 只写优点，不写护城河可能被侵蚀的路径。
- 把管理层个人魅力当作护城河。
