# 财务分析

把原始财报变成**可复算的财务事实**。不做估值，不做买卖判断。

## 何时使用

- 拿到新财报，需要判断"数字好不好、是不是真的"。
- 为 `intrinsic-valuation` 准备标准化财务基底。
- 不适用：只有新闻摘要、没有原始财报时——先去拿财报，不要用二手数据做财务分析。

## 输入

必需：年报或季报/中报原文（PDF 或 XBRL）、报告期、币种。
可选：上一期财报（算同比）、同业数据（做对比，但不得用于填充缺失值）。

## 流程

### 1. 建立报告清单

列出使用的文件：类型、报告期、发布日期、链接、页码。至少 5 年，能取 10 年就 10 年。
港股注意：中报是"中期报告"，没有强制季报；美股财年可能非 12 月。

### 2. 三表提取

按统一模板提取（`data/templates/financials.csv`）：

- 利润表：营收、毛利、营业利润、净利润、归母净利润、基本/稀释 EPS
- 资产负债表：现金及等价物、应收、存货、商誉、有息负债（短/长）、股东权益、少数股东权益
- 现金流量表：经营现金流、资本开支、自由现金流、回购、分红、股权融资

每格标注：数值、币种、单位、报告期、页码。缺失写 `NA` 并说明原因。

### 3. 利润质量

逐项排查：

| 检查 | 方法 | 红旗 |
| --- | --- | --- |
| 现金含量 | 经营现金流 / 净利润（5 年均值） | 长期 < 80% |
| 应收账款 | 应收增速 vs 营收增速 | 应收连续 2 年快于营收 |
| 存货 | 存货增速 vs 营收增速 + 跌价准备 | 存货积压、计提不足 |
| 非经常损益 | 处置收益、投资收益、公允价值变动占利润比 | > 20% 且被计入"核心利润" |
| 股权激励 | SBC / 营收，SBC / 净利润 | 高 SBC 且大量回购抵消稀释 |
| 研发资本化 | 开发支出资本化率（IFRS/HKFRS） | 资本化率显著高于同业 |
| 关联交易 | 关联方收入/采购占比 | > 20% 且定价不透明 |

### 4. ROIC 与资本回报

统一口径并在报告中写死：

```
NOPAT = EBIT × (1 - 实际税率)
投入资本 = 净营运资本 + 净固定资产 + 商誉及无形资产 + 其他经营资产
         （不含超额现金与有息负债的抵销，口径一旦选定不得中途更换）
ROIC = NOPAT / 平均投入资本
```

同时给 ROE 与杜邦拆解（净利率 × 周转率 × 杠杆），说明 ROE 是否由杠杆驱动。

### 5. 资产负债与偿债

- 净现金 / 净负债（定义写清：是否含受限制现金、理财、租赁负债）
- 短期有息负债 / 现金
- 利息保障倍数 = EBIT / 利息费用
- 表外项目：担保、诉讼、租赁承诺、养老金缺口
- 港股特有：永续证券计入权益还是负债、投资物业公允价值、联营公司投资占比

### 6. 股本与稀释

- 总股本（全部类别）、库存股、加权平均稀释股数
- 期权/可转债/ADS ratio 的潜在稀释
- 5 年股本变化：回购注销 vs 股权激励增发，净稀释率
- 港股：读最新月报表核对已发行股份

### 7. 分部与单位经济

- 分部收入、分部利润率、分部资本开支（能取到才写）
- 若公司只披露一个分部，明确写"无分部数据"，不要用行业数据替代

### 8. 输出异常清单

按严重程度排序，每条包含：异常现象、涉及科目、可能解释、需要什么证据确认。

## 输出

写入报告第 5 节，或独立成文 `reports/financial-analysis/<代码>-<YYYYMMDD>.md`，含：

1. 报告清单
2. 三表摘要（5–10 年）
3. 关键比率表（毛利率、营业利润率、ROIC、ROE、负债率、现金含量）
4. 异常清单
5. 会计口径调整说明（跨市场比较时必填）
6. 计算附录（公式 + 输入 + python 输出）

## 质量门

- [ ] 每个数字有来源与页码
- [ ] 币种、单位、报告期无遗漏
- [ ] 现金流/净利润至少 5 年
- [ ] ROIC 口径已写明，未中途更换
- [ ] 稀释股数已核对，ADS ratio 已确认
- [ ] 异常项都给了"需要什么证据"
- [ ] 跨市场比较时做了 GAAP/IFRS 调整说明

## 交接

- 上游：`company-research` 或用户直接提供的财报。
- 下游：`intrinsic-valuation` 用标准化后的营收/利润率/资本开支/税率；`investment-thesis` 用异常清单写风险。

## 禁止

- 用媒体"财报解读"代替财报原文。
- 用行业均值填补公司缺失数据。
- 只算比率不看口径（例如把含少数股东权益的净利润当归母）。
- 把 non-GAAP / 经调整净利润当作主口径而不说明。
