# 内在价值与估值

输出**区间 + 假设 + 敏感性**，不输出目标价。

## 何时使用

- `company-research` 的第 8 节。
- 用户问"现在贵不贵""合理估值多少"。
- 不适用：没有稳定现金流且无商业模式的早期公司（改用情景估值并标注 C 级）；银行/保险（用 P/B–ROE 或 DDM，见第 7 节）。

## 输入

必需：

- 标准化财务基底（来自 `financial-analysis`）：营收、EBIT、税率、D&A、资本开支、营运资本变化
- 股本结构：总股本、稀释股数、ADS ratio、净负债、少数股东权益
- 当前股价、币种、数据日期
- 护城河趋势结论（来自 `moat-analysis`），用于决定永续增长率与折现率

## 流程

### 1. 选择方法与理由

先写一句"为什么用这个方法"：

| 公司类型 | 主方法 | 辅助方法 |
| --- | --- | --- |
| 稳定现金流（消费、平台、公用事业） | FCFF DCF | 相对估值、反向 DCF |
| 多业务集团 | SOTP | 分部 EV/EBITDA |
| 银行/保险 | P/B–ROE、DDM | 相对估值 |
| 地产/收租 | NAV | 股息贴现 |
| 高增长未盈利 | 情景估值 + 终局倒推 | 反向 DCF |
| 周期股 | 中周期正常化盈利 | P/B、EV/替代成本 |

### 2. 标准化基底

- 剔除一次性损益、处置收益、公允价值变动
- 股权激励（SBC）视为**真实现金成本**，不剔除
- 维持性资本开支与增长性资本开支分开；分不开就用折旧近似并注明偏差方向
- 周期股用 5–7 年中周期平均利润率，不用峰值

### 3. 假设表（每个假设都要标注性质）

| 假设 | 取值（悲观/中性/乐观） | 性质 | 依据 |
| --- | --- | --- | --- |
| 未来 5 年营收 CAGR | 5% / 9% / 13% | 预测 | 行业增速 + 份额假设 |
| 稳态营业利润率 | 18% / 22% / 25% | 预测 | 历史区间 + 规模效应 |
| 实际税率 | 15% / 18% / 20% | 事实/预测 | 过去 3 年实际税率 |
| 资本开支/营收 | 6% / 5% / 4% | 预测 | 历史 + 管理层指引 |
| WACC | 9.5% / 8.5% / 7.5% | 假设 | 见下 |
| 永续增长率 g | 1.5% / 2.5% / 3.5% | 假设 | 不应长期高于名义 GDP |

`g` 的硬约束：若 g > 名义 GDP 增速（用长期通胀 + 实际增长估计），必须给出极强理由，否则视为模型错误。

### 4. 三情景 DCF

```
FCFF_t = EBIT_t × (1 - 税率) + D&A_t - 资本开支_t - ΔNWC_t
WACC   = E/V × Re + D/V × Rd × (1 - 税率)
Re     = Rf + β × ERP        （β 用 5 年月度，或行业 unlevered β 再加杠杆）
TV     = FCFF_{n+1} / (WACC - g)
EV     = Σ FCFF_t / (1+WACC)^t + TV / (1+WACC)^n
```

股权桥（必须逐项写清）：

```
股权价值 = EV - 有息负债 + 现金及等价物 - 少数股东权益 - 优先股
         + 联营/合营投资（按市值或账面，注明）
每股价值 = 股权价值 / 稀释后总股本
```

ADS 公司：先算每普通股价值，再乘以 ADS ratio。

### 5. 反向 DCF

固定其他假设，反解：**当前股价隐含的 10 年营收 CAGR 或永续增长率是多少？**
把这个隐含值与①历史增速②行业增速③你的中性假设对比，回答："市场预期比我们乐观/悲观多少，差异来自哪里。"

### 6. 相对估值互校

- P/E、EV/EBIT、EV/EBITDA、P/FCF、P/B（按行业选 2–3 个）
- 与自身 5–10 年区间比，与可比公司比（可比公司要说明选择理由）
- 关键：分母口径一致（GAAP vs non-GAAP、是否含 SBC、是否年化）
- 若相对估值与 DCF 结论差异 > 30%，必须解释是哪个假设造成的

### 7. 特殊行业

- **银行**：ROE × 可持续性 → 合理 P/B；用 DDM 交叉验证。不要用 FCFF。
- **保险**：分开承保利润与投资收益，用内含价值/新业务价值。
- **地产/REITs**：NAV = 投资物业公允价值 - 净负债；注意公允价值假设的资本化率。
- **周期**：中周期盈利 × 合理倍数，明确当前处于周期什么位置。

### 8. 敏感性

至少做二维表：WACC（±1%）× g（±1%）；再加一张利润率（±2pp）× 营收增速（±3pp）。
表格直接给出每股价值，不要只给定性描述。

### 9. 安全边际

```
安全边际 = (中性情景每股价值 - 现价) / 中性情景每股价值
```

再叠加不确定性要求（读 `knowledge/investors/li-lu.md`）：基础 20% + 信息丰富度扣分 + 治理风险。
结论写："现价对应中性情景折价 N%，低于/高于本标的所需的安全边际 M%，因此……"。

## 输出

→ 报告第 8 节，包含：

1. 方法选择与理由
2. 假设表（含性质标注）
3. 三情景每股价值区间
4. 反向 DCF 的隐含增长
5. 相对估值对照
6. 敏感性两张表
7. 安全边际结论
8. 计算附录（python 代码 + 输出）

**格式要求**：`中性情景每股价值 X–Y（币种），现价 Z，折价/溢价 N%`。

## 质量门

- [ ] 每个假设有性质标注（事实/预测/假设）
- [ ] g 与 WACC 有推导，不是拍的
- [ ] 股权桥逐项列示，稀释股数正确
- [ ] 反向 DCF 已算，并与中性假设对比
- [ ] 至少一种方法互校，差异 > 30% 已解释
- [ ] 敏感性表给出数值
- [ ] 所有计算用 python 复算，附录可复现
- [ ] 没有出现"目标价"

## 交接

- 上游：`financial-analysis` 的基底、`moat-analysis` 的趋势、`growth-analysis` 的增长假设。
- 下游：`investment-thesis` 用估值区间与安全边际写结论；`portfolio-review` 用区间判断持仓是否仍合理。

## 禁止

- 用单一方法、单一情景给结论。
- 为了让结论好看而调 WACC 或 g（禁止"倒推假设"）。
- 忽略少数股东权益、净负债、ADS 换算。
- 把 DCF 结果精确到小数点后两位——精度是假象。
- 用"行业平均 PE"直接乘利润当估值。
