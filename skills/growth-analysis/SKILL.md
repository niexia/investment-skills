# 成长股分析

回答：**增长从哪来、能持续几年、需要多少资本、市场已经定价了多少。**
不负责估值数字（交给 `intrinsic-valuation`），但负责给它提供增长假设。

## 何时使用

- 营收增速 > 10%，或处于科技/AI/平台/新能源等快速变化行业。
- 用户问"增速能不能持续""AI 对它到底是利好还是利空"。
- 不适用：稳态公用事业、成熟消费（用 `moat-analysis` + `intrinsic-valuation` 即可）。

## 输入

必需：5 年营收与分部数据、客户结构、行业规模数据来源、竞争对手数据。
可选：产业链上下游公司披露（用于交叉验证需求真实性）。

## 流程

### 1. 增长桥（Growth Bridge）

把过去 3 年的增长拆开，逐年做：

```
Δ营收 = 市场自然增长 + 份额变化 + 价格/产品结构 + 新业务 + 并购 + 汇率
```

每一项给出金额或百分点，无法拆分的写"未披露"，不要用"综合影响"糊过去。
目的：判断增长是**行业给的**还是**公司挣的**。行业给的增长在周期转向时会消失。

### 2. TAM / 渗透率

- 自上而下：TAM = 潜在客户数 × 年支出；自下而上：用可比公司收入反推。
- 两种方法结果差异 > 50% 时，说明 TAM 定义有问题，写清口径。
- 渗透率必须给数据来源与年份。渗透率 < 10% 与 > 50%，增长逻辑完全不同。
- 明确 SAM（可服务市场）与 SOM（可获取市场），不要用 TAM 直接算增长空间。

### 3. 行业结构与利润池

- 五力：新进入者、替代品、买方议价、供方议价、现有竞争。
- 利润池：产业链各环节的收入与利润率，公司所在环节的利润占比在上升还是下降。
- 判断：这家公司是在**扩大利润池**，还是只在**切别人的蛋糕**。

### 4. 技术路线与代际风险

- 技术 S 曲线位置：渗透率、性能提升速度、成本下降速度。
- 是否存在代际切换（架构、标准、能源形式），公司是受益方还是被替代方。
- 生态位：是否绑定某一平台/标准，绑定是保护还是风险。
- 时间窗口：替代发生的大致年份，以及公司的应对（自研、并购、第二曲线）。

### 5. 增长质量

| 指标 | 算法 | 判断 |
| --- | --- | --- |
| 增量 ROIC | ΔNOPAT / Δ投入资本 | 低于资本成本 = 增长毁灭价值 |
| 获客成本回收期 | CAC / 月度毛利贡献 | > 24 个月需警惕 |
| 毛利率轨迹 | 分部毛利率 3 年趋势 | 规模扩大但毛利率下降 = 无规模效应 |
| 资本强度 | capex / 营收 | 增长越重，越依赖融资 |
| 客户集中度 | 前 5 大客户占比 | > 30% 视为结构性风险 |
| 收入确认质量 | 应收/合同资产增速 vs 营收 | 快于营收 = 在用账期换增长 |

### 6. 可持续性（3–5 年）

给一个明确判断：

```
可持续增速区间：X%–Y%（未来 3 年）
主要驱动：<两项>
最先耗尽的驱动：<哪一项，大约何时>
```

增长驱动会"耗尽"：渗透率到顶、份额到顶、提价空间用尽、新业务亏损扩大。指出最早耗尽的那个。

### 7. AI / 科技产业链专项检查

适用于算力、半导体、云、模型、应用层：

- **资本开支周期**：超大规模客户 capex 增速，当前处于扩张期还是消化期？
- **供需**：算力/产能是否过剩？订单能见度几个季度？
- **客户集中**：前几大客户占比，是否自研替代（自研芯片、自建模型）？
- **价值链卡点**：HBM、先进封装、电力、网络带宽，谁在收租？
- **代际切换**：训练 → 推理的结构变化，对公司收入结构的影响。
- **折旧与会计**：GPU/服务器折旧年限假设，是否被拉长以美化利润。
- **泡沫检验**：如果终端需求增速减半，哪一环节最先崩？

### 8. 对估值的含义

- 给定增长目标，需要多少再投资（capex + 营运资本）？自由现金流何时转正？
- 反向问：当前估值隐含的 5 年 CAGR 是多少？与第 6 步的可持续区间比较。
- 明确写出交给 `intrinsic-valuation` 的三个数字：营收 CAGR、稳态利润率、资本开支强度。

## 输出

→ 报告第 7 节，包含：增长桥、TAM 与渗透率、利润池位置、技术路线风险、增长质量表、可持续增速区间、AI 专项结论（如适用）、给估值的三个假设。

## 质量门

- [ ] 增长桥逐年拆解，未拆分项已标注
- [ ] TAM 有口径与来源，渗透率有年份
- [ ] 增量 ROIC 已算
- [ ] 指出了"最先耗尽的增长驱动"
- [ ] 技术替代风险给了时间窗口
- [ ] 给估值的三个数字明确
- [ ] 没有把行业增速直接当作公司增速

## 交接

- 上游：`financial-analysis` 的分部数据、`moat-analysis` 的竞争结论。
- 下游：`intrinsic-valuation` 用可持续增速与资本强度建模型；`investment-thesis` 用"最先耗尽的驱动"写证伪条件。

## 禁止

- 用"AI 赋能""数字化转型"作为增长理由而不给量级。
- 用 TAM 大来证明公司能增长。
- 忽略客户集中度与自研替代风险。
- 把一次性涨价、并购并表、汇率当成内生增长。
