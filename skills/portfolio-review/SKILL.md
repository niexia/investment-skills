# 组合复盘

从"研究公司"上升到"管理组合"。输出**偏离与待办**，不输出交易指令。

## 何时使用

- 每季度一次例行复盘；财报季结束后一次。
- 用户问"我的仓位合理吗""是不是太集中了"。
- 不适用：单家公司研究（用 `company-research`）；还没有持仓记录时，先建 `portfolio/holdings.md`。

## 输入

必需：`portfolio/holdings.md`（持仓与成本）、`portfolio/allocation.md`（政策与阈值）、`reports/theses/` 下全部论点、最新股价与汇率。
缺失时先补记录，不要凭记忆估算权重。

若 `allocation.md` 仍保留“需要你确认或修改”的提示，或没有用户确认记录，将其中数值标为**暂定默认值**。可以展示实际暴露并做情景对照，但不得称其为用户风险偏好、据此判定政策越界或生成再平衡待办；在报告中注明政策尚未确认。

## 流程

### 1. 计算真实权重

- 以**市值**计权重，含现金；多币种统一折算，注明汇率与日期。
- ETF 需**穿透**到成分股，计算合并后的真实个股/行业暴露。
- 输出：总市值、各类资产权重、现金比例。

### 2. 集中度

| 指标 | 算法 | 参考阈值 |
| --- | --- | --- |
| 前 5 大持仓占比 | 按穿透后市值 | > 60% 提示集中 |
| 单一持仓上限 | 见 `allocation.md` | 超出即标记 |
| HHI | Σ w² | > 0.25 高度集中 |
| 单一行业占比 | 穿透后 | 见政策上限 |
| 单一市场/币种占比 | 按计价货币 | 见政策上限 |

阈值以 `portfolio/allocation.md` 为准，本表只是通用参考。

### 3. 暴露分析

- 市场：美股 / 港股 / 其他
- 币种：USD / HKD / CNY
- 行业与主题：是否多个持仓押注同一个宏观变量（如都是 AI 算力）
- 风格：成长 / 价值 / 高股息，是否无意中全部押一边
- 共同因子：利率敏感、中国消费、半导体周期——找出"看起来分散、实际同涨同跌"的组合

### 4. 论点状态盘点

逐个持仓读 thesis，标注：

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| 强化 | 新证据支持核心支柱 | 记录 |
| 稳定 | 无重大变化 | 记录 |
| 削弱 | 有支柱被削弱但未证伪 | 列入待办，重写论点 |
| 证伪 | 证伪条件已触发 | 必须重写论点，明确后续 |
| 未跟踪 | 没有 thesis 或超过 6 个月未更新 | 补研究或降级处理 |

**没有 thesis 的持仓一律标"未跟踪"**，这是组合里最大的隐性风险。

### 5. 政策偏离

仅在配置政策已确认时，对照 `allocation.md` 的区间：

| 项目 | 目标 | 实际 | 偏离 | 是否越界 |
| --- | --- | --- | --- | --- |
| 单一持仓上限 | ≤ 15% | 22% | +7pp | 是 |
| 现金下限 | ≥ 5% | 2% | -3pp | 是 |
| 港股占比 | 30%–50% | 48% | -2pp | 否 |

越界项写清"越界原因"（价格上涨导致被动超配 / 主动加仓 / 未再平衡）。若政策未确认，则将本节标为“暂定政策情景对照”，不得把偏离称为用户政策越界。

### 6. 财报与事件日历

- 未来 8 周内发布财报的持仓
- 已知的解禁、股东会、监管节点
- 每个事件对应 thesis 里的哪条证伪条件

### 7. 复盘：决策质量 vs 结果

用四象限归类每个决策：

| | 结果好 | 结果差 |
| --- | --- | --- |
| **流程对** | 应得的 | 运气不好，继续 |
| **流程错** | 运气好，危险 | 必须复盘 |

错误归因四类：认知错误（看错生意）、数据错误（用了错数字）、纪律错误（违反自己的规则）、运气。
**只对流程错误做改进，不对结果好坏做情绪化反应。**

### 8. 输出待办（不是指令）

每条待办写：对象、原因、动作类型、截止时间。动作类型只允许：

- `补研究`（没有 thesis 或数据过期）
- `更新论点`（支柱被削弱）
- `再平衡评估`（越界，需人工决定）
- `观察`（无动作，等待财报）
- `降级/退出评估`（论点被证伪，交由人决定）

## 输出

`reports/portfolio-review/<YYYYMMDD>-portfolio-review.md`，结构：

1. 一句话结论（组合整体状态：健康 / 需关注 / 需处理）
2. 权重与集中度
3. 暴露与共同因子
4. 论点状态盘点
5. 政策偏离表
6. 财报与事件日历
7. 决策复盘
8. 待办清单

## 质量门

- [ ] 权重按市值计算，ETF 已穿透
- [ ] 汇率与数据日期已注明
- [ ] 集中度用了至少两个指标
- [ ] 每个持仓都有论点状态
- [ ] 政策偏离逐项对照 `allocation.md`
- [ ] 暂定政策数值未被表述为用户已确认的风险偏好或硬约束
- [ ] 待办都是动作类型，不是"建议买入/卖出"
- [ ] 复盘区分了流程与结果

## 交接

- 上游：`portfolio/`、`reports/theses/`、`etf-analysis` 的穿透数据。
- 下游：把"补研究""更新论点"派回 `company-research` / `investment-thesis`。

## 禁止

- 因为短期涨跌建议调仓。
- 用"均衡配置"作为不思考的借口。
- 在不知道持仓的情况下给出组合建议。
- 替用户决定买卖与仓位数字。
