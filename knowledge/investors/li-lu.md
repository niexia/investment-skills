# 李录框架

用于回答"十年后它还在吗，而且更强吗"。在本系统中承担**长期确定性**的检验。

## 核心问题

1. 这家公司所处的行业，是否处在文明演进的长期趋势上（而非短期风口）？
2. 十年后，它的产品或服务是变得更重要，还是被替代？
3. 它的竞争优势是**结构性**的（规模、网络、数据、牌照、成本曲线），还是**阶段性**的（先发、补贴、监管窗口）？
4. 管理层是否具备在长周期里做正确决策的能力与耐心？
5. 当前价格是否提供了足够的安全边际来承受"我看错了"的概率？

## 长期确定性的三个来源

| 来源 | 判断标准 | 常见误判 |
| --- | --- | --- |
| 需求的结构性增长 | 渗透率仍低 + 单位经济随规模改善 | 把周期性反弹当结构增长 |
| 竞争格局稳定 | 前三名份额稳定、价格战不频繁 | 把"暂时没有对手"当护城河 |
| 资本回报可持续 | ROIC 长期高于资本成本，且不靠杠杆 | 用会计利润代替现金流 |

## 文明趋势 / 范式转移

- 只判断**方向**，不预测**节奏**。方向对了但早十年，同样是失败的投资。
- 区分"技术可行"与"商业可行"：前者靠论文，后者靠单位经济。
- 范式转移期最大的风险不是看错方向，而是**买在渗透率 60% 之后**——此时增长放缓而估值仍按早期定价。

## 安全边际的另一种定义

李录的安全边际更多来自**理解深度**：对生意、管理层、行业结构的理解越深，需要价格提供的保护越少；理解越浅，需要的折扣越大。

在本系统中量化为：

```
要求的安全边际 = 基础折扣（20%） + 不确定性溢价
不确定性溢价 = 信息丰富度扣分（B: +10%，C: +25%） + 治理风险（有红旗: +15%）
```

这是**内部纪律**，不是市场规律。它只用于判断"当前价格是否给了足够补偿"，不用于生成买入价。

## 三条否决

1. 行业处于被替代的末期，且公司没有第二曲线。
2. 竞争优势依赖单一监管政策，且政策方向不可预测。
3. 管理层在长周期决策上出现过"为短期业绩牺牲长期竞争力"的记录，且未修正。

## 在本系统中的用法

- `growth-analysis`：判断增长是结构性还是阶段性。
- `intrinsic-valuation`：把不确定性溢价写进安全边际要求。
- `investment-thesis`：论点必须回答"十年后为什么还在"，答不上来就不能给"通过"。
