# 芒格框架

核心不是选股技巧，而是**避免愚蠢**。在本系统中承担"反方与风险"角色。

## 逆向思考（Inversion）

不问"这家公司怎么会成功"，先问：

1. 这家公司**怎么会死**？列出 5 条具体路径。
2. 什么情况下这笔投资会永久性亏损（不是浮亏）？
3. 如果我是一个想做空它的聪明人，我会攻击哪里？
4. 三年后回看，最可能让我后悔的是什么？

## 多元思维模型（只列与投资直接相关的）

| 模型 | 用途 |
| --- | --- |
| 规模经济 / 范围经济 | 判断成本优势能否持续 |
| 网络效应与临界规模 | 判断平台型生意的稳定性 |
| 激励结构（Incentives） | 管理层、销售、渠道的真实动机 |
| 代理问题 | 管理层与股东利益是否一致 |
| 社会认同 / 从众 | 识别市场共识与自己的偏差 |
| 路径依赖 | 技术路线、组织能力的惯性 |
| 冗余与安全边际 | 工程学思维：好系统需要缓冲 |
| 复利与时间 | 长期回报的来源，也是错误的放大器 |
| 机会成本 | 一切决策的基准是对比最好的替代选项 |
| 能力圈 | 知道边界比扩大边界更重要 |

## 风险清单（每次研究必过）

- [ ] 会计口径是否被用来美化利润（一次性收益、资本化、关联交易）？
- [ ] 增长是否依赖单一客户 / 单一产品 / 单一监管许可？
- [ ] 管理层是否有过损害小股东的记录？
- [ ] 行业是否正在被技术替代，而公司自己不愿承认？
- [ ] 杠杆是否让公司在低谷期被迫做傻事？
- [ ] 估值是否假设了"这次不一样"？
- [ ] 我是不是因为喜欢这家公司而放松了标准？

## 三条硬规则

1. **反过来想，总是反过来想。** 任何正面结论必须配一段同等强度的反面论证。
2. **如果无法用简单语言说清风险，就是没想清。** 复杂叙事往往是风险的藏身处。
3. **避免"确认偏误"**：主动找 3 条与自己结论相反的证据，找不到说明搜索不够。

## 在本系统中的用法

- `moat-analysis`：用"替代品测试"与"新进入者测试"检验护城河。
- `investment-thesis`：必填反方论证、失败路径、证伪条件。
- `portfolio-review`：用机会成本与集中度检验组合是否在"做傻事"。

## 与巴菲特的张力

巴菲特问"够不够便宜"，芒格问"会不会归零"。
结论冲突时不取平均：**先过芒格的风险关，再谈巴菲特的价格关。** 顺序不能反。
