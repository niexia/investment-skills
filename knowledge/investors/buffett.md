# 巴菲特框架

只保留能直接用于判断的问题与标准，不模仿语气。

## 四个核心问题

1. **我能理解这门生意吗？** 十年后它大概还在卖什么？如果说不清收入从哪来，就是能力圈外。
2. **它有持久的竞争优势吗？** 护城河是结构性的事实，不是"品牌很好"的感觉。
3. **管理层诚实且有能力吗？** 看资本配置记录，不看访谈措辞。
4. **价格相对于价值有足够折扣吗？** 好公司 + 高价格 = 坏投资。

## 护城河的四种真形式

| 类型 | 检验方式 | 常见伪护城河 |
| --- | --- | --- |
| 网络效应 | 用户增加是否让每个用户获得更多价值 | 用户多但单用户价值下降 |
| 转换成本 | 客户迁移的实际成本（数据、流程、合同、培训） | 客户抱怨多但仍在用 |
| 成本优势 | 单位成本长期低于对手且对手无法复制（规模、位置、资源） | 靠补贴换来的低价 |
| 品牌/信任 | 能否在不流失客户的前提下提价 | 知名度高但无定价权 |

**关键判断**：护城河在变宽还是在收窄？趋势比当下的宽度更重要。

## 财务标准（经验值，非教条）

- 长期 ROE > 15%，且**低杠杆**达成（高杠杆堆出的 ROE 不算）
- 毛利率稳定或上升，说明有定价权
- 经营现金流 / 净利润长期 > 80%，否则利润可能是账面的
- 资本开支需求低（"护城河越宽，越不需要花钱维持"）
- 股本长期不稀释，最好持续减少
- 有息负债低，或能被 2–3 年自由现金流覆盖

## 所有者收益（Owner Earnings）

```
所有者收益 = 净利润
           + 折旧摊销等非现金费用
           - 维持性资本开支（不是全部资本开支）
           - 必要的营运资本增加
```

难点在"维持性资本开支"的拆分：用折旧近似是下策，应看公司披露的产能维护性投入与增长性投入。若无法拆分，明确写"用折旧近似，可能高估/低估"。

## 估值纪律

- 用**长期无风险利率 + 风险溢价**贴现，不用当前市场情绪调整贴现率。
- 宁可模糊的正确：给出区间，不给小数点后两位的目标价。
- 安全边际来自：① 生意确定性高 ② 价格折扣大 ③ 下行有资产/现金流保护。三者至少占两个。
- 反向问：当前价格隐含的永续增长率是多少？如果超过名义 GDP 增速，需要极强理由。

## 常见错误（他自己承认过的）

- 为"故事"付钱（航空、纺织、早年伯克希尔）。
- 用便宜的价格买糟糕的生意（"烟蒂股"），时间价值被糟糕生意吃掉。
- 因为宏观预测而放弃好公司。
- 规模变大后，可投资标的变少，回报率必然下降。

## 在本系统中的用法

- `moat-analysis`：用护城河四型 + 趋势判断。
- `financial-analysis`：用所有者收益与 ROE 质量。
- `intrinsic-valuation`：用区间估值 + 反向 DCF + 安全边际三条件。
- 与芒格冲突时：巴菲特看"便宜"，芒格看"会不会死"，两者都过才算通过。
