# 美股与港股：不能互相照搬的差异

写作与建模前必读。所有条目在具体公司上都要回到原始披露核实，本文件只提供检查方向。

## 1. 披露体系

| | 美股 | 港股 |
| --- | --- | --- |
| 监管 | SEC | HKEX + SFC |
| 披露平台 | EDGAR（`sec.gov`，含 XBRL） | HKEXnews（`hkexnews.hk`） |
| 年报 | 10-K（财年结束后 60–90 天） | 年报（财年结束后 3 个月内） |
| 季报 | 10-Q（每季，强制） | **无强制季报**；中报（半年，2 个月内）+ 自愿季度公告 |
| 临时公告 | 8-K | 翌日披露报表、内幕消息公告、月报表 |
| 股东会 | DEF 14A（含薪酬、持股） | 股东周年大会通函 |
| 特殊披露 | S-1、20-F（外国私人发行人）、13F | 招股书、通函、月报表（股本变动） |

**港股特有但极有用的文件**：月报表（Monthly Return）——每月股本变动、已发行股份数，是核对总股本与市值的一手来源。

## 2. 财年

两家市场都允许非 12 月财年，不能默认日历年：

- 美股：Apple 9 月底、Microsoft 6 月底、NVIDIA 1 月底。
- 港股：阿里巴巴 3 月底。

写作规范：`FY2026（2025-04-01 至 2026-03-31）`，不要只写"2026 年"。

## 3. 币种

| 场景 | 美股 | 港股 |
| --- | --- | --- |
| 交易货币 | USD | HKD |
| 财报货币 | USD（绝大多数） | **人民币或港元**（腾讯、阿里为人民币；汇丰为美元） |
| 股息 | USD，通常季度 | HKD 或财报货币，通常半年/年度 |

港股最常见错误：把人民币营收、港元股价直接相除算 PE。必须先统一币种，并记录汇率与日期。

## 4. 会计准则

| 议题 | US GAAP | IFRS / HKFRS | 影响 |
| --- | --- | --- | --- |
| 研发支出 | 基本全部费用化（除软件） | 开发阶段满足条件可资本化 | 港股科技公司利润可能被资本化抬高 |
| 投资物业 | 通常成本模式 | 允许公允价值模式 | 港股地产/收租股利润含重估收益，需剔除 |
| 商誉减值 | 只做减值测试，不可转回 | 减值不可转回 | 一次性大额减值频发 |
| 股权激励 | 费用化 | 费用化 | 两家都要看 SBC 占收入比 |
| 非经常项 | 公司自定义 non-GAAP | 公司自定义"经调整净利润" | 不可直接比较，必须自己重算 |

跨市场比较前，至少调整：研发资本化、投资物业公允价值变动、SBC、一次性处置收益。

## 5. 股本与证券类型

- **美股**：多类别股份（GOOGL/GOOG）；ADS 与普通股有换算比例（如阿里 1 ADS = 8 股普通股，**以最新 20-F 为准**）；市值必须用全部类别股份。
- **港股**：同股不同权后缀 `-W`（如 9988、3690）、二次上市 `-S`、未盈利生物科技 `-B`（18A）。计算市值用**全部**股份，包括未上市的 B 类股。
- **A+H**：同一公司在两地上市，价格可以长期不同（AH 溢价）。港股估值不能用 A 股价格，反之亦然。

## 6. 交易机制

| | 美股 | 港股 |
| --- | --- | --- |
| 交收 | T+1 | T+2 |
| 涨跌幅限制 | 无（有个股波动熔断） | 无 |
| 收盘 | 16:00 ET，有盘后交易 | 16:00 HKT，16:00–16:10 收市竞价 |
| 恶劣天气 | 正常交易 | 台风/黑雨可停市或延迟 |
| 假期 | 美国假日 | 香港假日 + 内地假期影响港股通 |

研究结论里的"现价"必须注明时间戳与时区，跨市场组合还要注明汇率。

## 7. 估值口径陷阱

1. **EV 计算**：港股常有大额少数股东权益、永续证券、联营公司投资，EV 口径差异极大。写清楚 `EV = 市值 + 有息负债 + 少数股东权益 + 优先股 - 现金`。
2. **现金定义**：受限制现金、客户备付金、理财产品是否计入？两家市场都要看附注。
3. **每股价值**：用稀释后股本（含期权、可转债、ADS 换算），不用基本股本。
4. **PE 的分子**：GAAP 净利润 vs non-GAAP vs 经调整净利润，三者可能差 30% 以上。报告里必须写明用的是哪一个。
5. **SOTP**：港股综合企业（控股公司）折价长期存在，SOTP 结果要扣 holding company discount，并说明取值理由。

## 8. 研究港股前的六个必做动作

1. 打开 HKEXnews，拉最近 3 年年报 + 最近 2 期中报 + 最近 12 个月公告。
2. 读最新月报表，核对已发行股份数与回购注销情况。
3. 确认财报货币与交易货币，记录汇率。
4. 确认是否有 `-W` / `-S` / `-B` 后缀及其含义。
5. 检查是否存在 A 股或美股同名上市主体，避免张冠李戴。
6. 确认财年截止日，把"2025 年"改写成"FY2025（起止日期）"。

## 9. 研究美股前的四个必做动作

1. 在 EDGAR 确认 10-K / 10-Q / 8-K 清单与最新提交日期。
2. 读最新 10-K 的 `Item 1A Risk Factors` 与 `Item 7 MD&A`。
3. 核对 10-K 封面上的股份数（as of 最新日期）与 diluted shares。
4. 若有 ADS，确认 ADS ratio 与存托银行。
