所有研究类 skill 的终点是这份备忘录。可以只写其中几节（单点 skill），但**章节编号与标题不得改动**，缺失的章节写"本章不适用（原因）"。

## 结构

### 0. 元信息

```yaml
公司: 腾讯控股
代码: 0700.HK
市场: 港股（主板）
行业: 互联网平台
报告类型: 公司深度研究
数据截止: 2026-11-21
币种: 人民币（财报）/ 港元（股价）
信息丰富度: A
上游输入: 2025 年报、2026Q3 季报、HKEXnews 公告 12 份
本次结论: 有条件通过
```

### 1. 一句话结论

≤ 40 字，必须包含：生意判断 + 估值判断 + 结论档位。
反例："公司基本面良好，估值合理，值得关注。"
正例："社交网络护城河稳定，当前价格隐含 8% 永续增长，安全边际不足，有条件通过。"

### 2. 结论档位与条件

| 档位 | 定义 |
| --- | --- |
| 通过 | 生意、护城河、管理层、估值四关全过，且反方论证未能击穿核心逻辑 |
| 有条件通过 | 核心逻辑成立，但存在 1–2 个必须在指定时点验证的条件 |
| 灰色地带 | 关键变量无法验证，或证据内部矛盾，或估值区间跨越"贵/便宜" |
| 不通过 | 触发一票否决，或估值显著高于合理区间上限，或核心逻辑被证伪 |

"有条件通过"必须写出条件、验证时点、不满足时的处理。

### 3. 生意本质

- 卖什么、卖给谁、怎么收钱、单位经济（unit economics）
- 收入结构与利润结构（分部收入、分部利润率、占比）
- 成本结构与经营杠杆来源
- 一句话：这是一门什么生意？它赚的是谁的钱？

### 4. 护城河

- 类型：网络效应 / 转换成本 / 规模经济 / 品牌 / 牌照 / 成本优势 / 数据
- 宽度与**趋势**（变宽 / 稳定 / 收窄），趋势比宽度重要
- 证据：份额、留存、定价权、毛利率稳定性、客户集中度、替代品测试
- 反面测试：如果明天出现一个资源充足的对手，它需要多久、多少钱才能复制？

### 5. 财务质量

至少 5 年（能取到 10 年就 10 年）：

| 指标 | 看什么 |
| --- | --- |
| 收入 / 毛利率 / 营业利润率 | 增长质量与经营杠杆 |
| 经营现金流 / 净利润 | 利润含金量（长期应 > 80%） |
| 自由现金流 | 扣除维持性资本开支后的真实可分配现金 |
| ROIC / ROE | 资本回报，ROIC 优于 ROE |
| 有息负债 / 净现金 | 抗风险能力 |
| 股本变化 | 稀释速度 |
| 应收 / 存货 / 合同负债 | 是否在用营运资本换增长 |

会计口径提示：US GAAP 与 IFRS 在研发资本化、股权激励、投资物业公允价值、商誉减值上不同，跨市场比较前必须调整。

### 6. 管理层与资本配置

- 创始人/职业经理人、持股、薪酬与激励结构
- 历史资本配置：回购、分红、并购、扩张的成功率
- 承诺 vs 兑现的记录（找 3 个具体例子）
- 诚信红旗：关联交易、频繁变更口径、大股东减持、审计意见

### 7. 成长驱动（3–5 年）

- 增长来自：行业增长 × 份额提升 × 提价 × 新业务
- 逐项给量级与可持续性判断，不要只写"受益于 AI"
- 明确哪一部分增长是**一次性**的

### 8. 估值

必须包含：

1. **方法选择与理由**（DCF / 反向 DCF / 相对估值 / SOTP / 分部加总），至少两种互校
2. **假设表**：营收增速、利润率、税率、资本开支、营运资本、WACC、永续增长率；每个假设标注来源（事实 / 假设）
3. **三情景**（悲观 / 中性 / 乐观）及对应每股价值
4. **反向 DCF**：当前价格隐含了什么增长假设？这个假设合理吗？
5. **敏感性表**：WACC ±1%、永续增长 ±1% 对估值的影响
6. **安全边际**：现价相对中性情景的折扣，以及"需要多大折扣才值得承担不确定性"的理由

输出格式：`中性情景每股价值 X–Y（币种），现价 Z，折价/溢价 N%`。禁止输出单一"目标价"。

### 9. 市场预期与我们的差异

- 卖方一致预期（营收/EPS，来源与日期）
- 当前估值在自身历史区间与同业中的位置
- 我们的预测与 consensus 的差异，以及差异来自哪个假设
- 如果和 market 一致，说明"没有 edge"，这本身是结论

### 10. 反方论证与失败路径

- 最强空头论证（steelman，≥3 条）
- 3–5 条失败路径 + 粗略概率 + 触发信号
- 我们可能错在哪：列出最脆弱的 2 个假设

### 11. 证伪条件与跟踪指标

必须是可观测、有阈值、有检查时点的表格：

| # | 指标 | 当前值 | 证伪阈值 | 检查时点 | 数据来源 |
| --- | --- | --- | --- | --- | --- |
| 1 | 微信 MAU | 13.9 亿 | 连续两季 < 13.5 亿 | 每季财报 | 季报 |
| 2 | 游戏收入增速 | +12% YoY | 连续两季 < 0% | 每季财报 | 季报 |

"关注竞争格局变化"不是证伪条件。

### 12. 数据与来源

表格列出所有关键数字：指标、数值、币种、单位、报告期、来源、置信度。
另附：本次未能获取的数据、原因、补数路径。

### 13. 未知项与下一步

- 仍未解决的问题（按重要性排序）
- 下一步要查的具体文件/数据
- 本次研究不适用的范围（如未覆盖子公司、未做税务调整）

## 写作规范

- 正文 2,000–4,000 字；表格不计。超过 4,000 字说明没做取舍。
- 先结论后论证；每节开头一句话给判断，再给证据。
- 不用"显著""大幅""强劲"等形容词替代数字。
- 不写"综上所述""值得注意的是""在当今环境下"。
- 每个判断后面跟证据或标注"这是判断"。
- 币种、单位、报告期三者缺一不可。
