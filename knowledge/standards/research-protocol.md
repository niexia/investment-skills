# 研究协议

所有 skill 共用的证据、计算与不确定性的处理规则。与 [`AGENTS.md`](../../AGENTS.md) 冲突时以 AGENTS.md 为准。

## 1. 信息丰富度评级

研究开始前先给标的定级，并写在报告头部。评级决定结论的信心上限。

| 级别 | 标准 | 对结论的影响 |
| --- | --- | --- |
| **A** | 上市 ≥ 5 年，连续披露完整，有可比公司、有卖方覆盖、有长期股价历史 | 可以给出区间估值与明确结论 |
| **B** | 上市 2–5 年，或披露不完整、分部数据缺失、无卖方覆盖 | 估值必须给区间 + 置信度，结论最多"有条件通过" |
| **C** | 上市 < 2 年、未上市、重大重组中、披露口径频繁变更 | 只做事实梳理与情景假设，结论只能是"灰色地带" |

评级不是免责声明。A 级公司同样可能看错，C 级公司也可能有极高确定性——评级管理的是**证据密度**，不是投资价值。

## 2. 来源分层

```
S1  原始披露     SEC 10-K/10-Q/8-K/DEF 14A；HKEXnews 年报/中报/公告/通函；招股书；公司 IR
S2  结构化数据   XBRL、交易所行情、指数公司官网、ETF 官网、FRED、HKMA
S3  第三方       Wind/彭博/Choice、券商研报、行业数据库
S4  二手信息     媒体、公众号、雪球、AI 摘要
```

规则：

- 数字只能来自 S1/S2。S3 用于交叉验证或获取市场预期（consensus），S4 仅用于发现线索。
- 同一指标有两个来源时，S1 覆盖 S2 覆盖 S3。偏差 > 1% 必须解释原因（口径、汇率、时点、股本变化）。
- 引用格式：`（来源名称，文件/页面，报告期，日期，链接）`。没有链接就写文件路径与页码，不允许"据报道"。

## 3. 三分法：事实 / 推断 / 预测

每个段落里的句子必须能归类：

- **事实**：来自 S1/S2，可复核。写法："2025 年经营现金流净额 X 亿元（来源）。"
- **推断**：由事实推出，标明推理链。写法："据此推断，资本开支强度将从 A% 降至 B%——依据是 X 与 Y。"
- **预测**：作者假设。写法："假设 2027–2030 年营收 CAGR 为 12%（假设依据：…；这是预测，不是事实）。"

报告中三类内容不得混在同一句里。估值模型的所有输入必须能追溯到一个事实或一条显式假设。

## 4. 置信度标注

关键数据点标置信度，尤其 B/C 级标的：

- 🟢 高：来自 S1，口径清晰，已交叉验证
- 🟡 中：来自 S2/S3，或口径需调整，或只有单一来源
- 🔴 低：推算值、行业估算、管理层口头指引

🔴 数据不得单独支撑估值结论。若某关键假设只有 🔴 数据，写"该假设无法验证"，并做敏感性分析说明结论对该假设的依赖。

## 5. 计算

1. 所有比率、增速、占比、CAGR、估值倍数，用公式复算，并在附录给出输入。
2. 优先用 `python3` + `decimal.Decimal`；禁止心算后直接写结论。
3. 市值校验：`股价 × 总股本`，与数据源市值比对，偏差 > 2% 必须归因。
4. 单位统一到"亿"时注明原始单位；跨币种换算给出汇率与日期。
5. 每股价值计算前核对：总股本（含全部投票权类别）、ADS ratio、期权/可转债稀释、少数股东权益、净现金/净负债定义。

常用校验（可在报告附录直接贴）：

```bash
python3 - <<'PY'
from decimal import Decimal as D
price, shares = D("380"), D("9.11e9")   # 港元、股
print("市值(亿港元):", price*shares/D("1e8"))
PY
```

## 6. 反方论证的硬要求

任何结论都必须先通过"反方"一关：

1. 至少 3 条**非稻草人**的空头理由，每条附带可观测证据或具体机制，而不是"竞争加剧"这类空话。
2. 站在空头立场写一段最强的论证（steelman），不得用削弱版。
3. 回答："如果这家公司三年后表现很差，最可能是哪条路径？"给出 3–5 条失败路径及粗略概率。
4. 明确"市场当前在担心什么"与"我们认为市场错在哪里"，两者必须分开写。

## 7. 留白

- 数据不足就写"未知"，并注明：缺什么数据、在哪里能拿到、拿到后结论会怎么变。
- 不允许用行业均值、竞品数据、历史趋势填补公司自身缺失的关键数据。
- 灰色地带是合法结论。宁可"无法判断"，不可"看起来不错"。

## 8. 更新与版本

- 报告头必须写数据截止日（`Data as of`），不是写作日。
- 重新研究同一标的时，先读上一份论点，逐条对比：哪些假设被验证、哪些被推翻、哪些仍未决。
- 论点变化必须写进报告的"与上版差异"一节，不允许静默改写结论。
