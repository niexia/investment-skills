# 投资原则

这是**方法论与纪律**，不是仓位数字。仓位上限、集中度、再平衡阈值在 [`portfolio/allocation.md`](../../portfolio/allocation.md)。

## 一、我们的优势与劣势

| 优势 | 劣势 |
| --- | --- |
| 没有赎回压力，可以长期持有 | 没有信息优势，拿不到一手调研 |
| 可以只在自己懂的领域下注 | 时间有限，覆盖公司数量有限 |
| 可以承受波动，不需要每季度好看 | 容易受叙事影响，高估自己的判断力 |

结论：**不拼信息速度，拼理解深度与纪律**。不做事件驱动、不做短线、不预测宏观。

## 二、三条不可让渡的原则

1. **只买能理解的公司。** 说不清十年后它靠什么赚钱，就不买。
2. **价格是决策的一部分。** 好公司买贵了也是坏投资；但便宜不能弥补生意质量的缺陷。
3. **先想怎么亏，再想怎么赚。** 任何论点必须附带证伪条件。

## 三、决策流程

```
筛选（六关）→ 深度研究（company-research）→ 论点（investment-thesis）
   → 估值区间与安全边际 → 组合层面检查（portfolio-review）→ 记录决策
```

任何一步不通过就停止。不允许"先买了再研究"。

## 四、持仓纪律

- 买入理由必须能写成五句话（镜子测试），说不完整就不买。
- 每次加仓必须重新写一遍论点，不能因为"跌了"而加。
- 卖出只有三个理由：① 论点被证伪；② 估值显著高于合理区间上限；③ 出现更好的机会（机会成本）。
- 股价下跌本身不是卖出理由，也不是加仓理由。
- 不做空、不使用杠杆、不买看不懂的结构化产品。

## 五、认知纪律

- 区分**事实、推断、预测**，三者不能混写。
- 主动寻找反面证据；找不到说明搜索不够，不代表没有。
- 对"这次不一样"保持最高警惕；对"永远如此"同样警惕。
- 承认不知道。研究报告中"未知"的比例，是诚实度的指标。
- 定期回看自己过去的判断，记录错误原因（认知错误 / 数据错误 / 运气）。

## 六、宏观

- 不预测利率、汇率、GDP。
- 宏观只做两件事：① 判断是否处于极端状态（影响安全边际要求）；② 检查持仓的币种与地域集中度。
- 不因为宏观观点调整长期仓位。

## 七、这套系统不做什么

- 不生成买卖信号，不承诺收益。
- 不替代原始披露阅读。AI 的输出必须回到年报/10-K 核对。
- 不因为"AI 说好"就下决定。最终判断由人负责。
