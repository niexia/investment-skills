# 数据层

分析质量的上限由数据质量决定。这一层的目的不是"存数据"，而是**让每个数字可追溯**。

## 原则

1. **原始披露优先。** S1（SEC / HKEXnews / 公司 IR）覆盖一切其他来源。
2. **保留上下文。** 每个数据点必须带：报告期、币种、单位、来源、抓取日期。
3. **事实与预测分离存放。** 预测值不得写进 `financials`，只能写在报告里并标注假设。
4. **不做静默修正。** 数据更正要留痕：旧值、新值、原因、日期。
5. **港美股分开。** 交易日、币种、财年、会计准则不同，不共用同一张表的口径。

## 目录

```
data/
├── README.md                  # 本文件
├── sources.md                 # 数据源登记表（可用性、成本、限制）
├── companies/
│   └── <代码>.md              # 公司事实卡（股本、结构、关键指标）
├── financials/
│   └── <代码>-<财年>.csv      # 标准化三表（可选，小规模用事实卡即可）
├── market/
│   └── <YYYYMMDD>-prices.csv  # 价格快照 + 汇率
└── templates/
    ├── company.md
    └── financials.csv
```

代码格式：`0700.HK`、`AAPL.US`。同一公司多地上市时，每条上市记录单独一行，并在事实卡里写明关系。

## 事实卡要求

每家公司一张卡，至少包含：

- 基本信息：全称、代码、市场、行业、财年截止日、财报货币、交易货币
- 股本：总股本（全部类别）、库存股、稀释股数、ADS ratio
- 股东结构：前十大、管理层持股、南向/外资占比（如可得）
- 关键财务（5–10 年）：营收、毛利率、营业利润、净利润、经营现金流、capex、FCF、ROIC
- 分部收入与利润率
- 公告清单：日期 + 类型 + 链接（最近 12 个月）
- 数据截止日与未获取项

## 价格与汇率快照

- 每次研究存一份 `data/market/<YYYYMMDD>-prices.csv`：代码、收盘价、币种、日期、来源。
- 汇率同理：USD/HKD、USD/CNY、HKD/CNY，注明来源与时间。
- 价格只用于当时点估值，**不得**用旧快照做新研究而不更新日期。

## 不入库的内容

- 券商研报全文、付费数据库导出（版权与许可风险）。
- 媒体文章原文（可记链接）。
- 未标注来源的"行业数据"。
- 预测值、目标价、评级。
