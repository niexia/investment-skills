# 路线图

原则：**先能稳定产出，再谈自动化**。每个阶段有明确的验收标准，不达标不进下一阶段。

**目标**：输入 `腾讯` / `Apple` / `Microsoft`，产出带来源、带估值、带反方论证、带证伪条件的备忘录。

- [x] 8 个 skill 的骨架与跨 Agent 发现：`skills/` 源码 + `.agents/skills` 单一项目级根目录
- [x] 跨 Agent 安装：npm CLI、离线脚本与插件清单（默认三个用户级根目录，另可指定 Agent）
- [x] Claude Code / Gemini CLI 入口：`CLAUDE.md`、`GEMINI.md` 指向 `AGENTS.md`
- [x] 证据规范 `knowledge/standards/research-protocol.md`

- [x] 数据层规范与来源登记
- [x] 报告、论点、组合复盘模板

### 待完成（本阶段的真正验收）

- [ ] 用 `company-research` 完成 3 家公司：1 家港股、1 家美股、1 家已持仓

## 阶段 2 · 成长股与指数投资

**目标**：AI 产业链与科技成长股可研究，ETF 与资产配置可执行。

### 要做的

- [ ] `knowledge/industries/`：AI 算力、半导体、云与模型、互联网平台四个行业的利润池与关键指标
- [ ] `growth-analysis` 增加行业专用检查表（资本开支周期、代际切换、客户自研替代）
- [ ] 数据脚本：SEC XBRL 拉取标准化三表（替代手工抄数）
- [ ] 数据脚本：港股 PDF 财报关键表提取（谨慎，需人工复核）
- [ ] `etf-analysis` 增加"穿透到成分股"的简化方法
- [ ] 建立核心 ETF 候选池（宽基 + 地区 + 行业），每个附方法论与费率对比
- [ ] 资产配置再平衡的计算脚本（只算偏离，不给指令）

**验收标准**：能回答"NVIDIA 当前价格隐含了什么增长""沪深300 / 标普500 / 恒生科技怎么配"，并给出可复核的数字。

## 阶段 3 · 投资 Agent 自动化

**目标**：从一次性分析工具，变成持续跟踪的个人助手。

### 要做的

- [ ] 财报日历：自动列出持仓与观察池的下次财报日期（DSH scheduled task）
- [ ] 财报后自动触发：`financial-analysis` → 对比证伪条件 → 提示是否重写论点
- [ ] 论点漂移检测：对比两版论点，区分事实变化 / 估值变化 / 措辞变化
- [ ] 报告索引：自动生成 `reports/README` 的按公司/时间索引
- [ ] 季度复盘自动起草（人只做判断）
- [ ] 决策日志与组合表现归因（流程 vs 结果）

**验收标准**：一次财报发布后，系统能在 30 分钟内给出"哪些证伪条件被触发、论点是否需要重写"的清单，且不产生任何买卖指令。

## 明确不做

- 自动下单、自动调仓。
- 基于技术指标或资金流的择时。
- 爬取付费数据或规避网站条款。
- 用 LLM 直接生成财务数字而不回原始披露核对。
